# Блогикум

Учебный сайт на Django: лента публикаций, страницы отдельных записей, категорий и информационные страницы.

Записи пока заданы в Python. Редактора, регистрации пользователей и хранения публикаций в базе данных нет; страница категории выводит её название без фильтрации записей.

**Технологии:** Python · Django · HTML/CSS · pytest.

## Запуск

Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python blogicum/manage.py runserver
```

В Windows активируйте окружение командой `.venv\Scripts\Activate.ps1`. Сайт доступен по адресу http://127.0.0.1:8000/.

Тесты маршрутов запускаются командой `pytest` из корня репозитория. В текущих тестах есть повреждённые ожидаемые строки; их наличие не означает, что набор проходит.

Проект предназначен для локального обучения. Настройки и версия Django требуют подготовки перед размещением в интернете.
